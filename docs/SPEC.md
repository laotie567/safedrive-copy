# 规格 · SafeDrive Copy

版本 1.0 · 状态：定稿

## 目标

macOS ⇄ NTFS 移动硬盘的双向**安全复制**工具：拖拽操作、零删除、绝不覆盖。

## 环境

- macOS 12+（在 macOS 26.5 Apple Silicon 上开发验证）
- 编译：Xcode Command Line Tools 提供的 `swiftc`，无第三方依赖
- NTFS 写入依赖外部驱动（FUSE-T + ntfs-3g，或商业驱动），工具本身不绑定任何卷名

## 安全铁律（frozen，违反任一条 = 验收失败）

- **S1 禁止删除**：主程序不链接任何通用删除 API（`removeItem` / `moveItem` / `trashItem` / `unlink`），源码 grep 零命中
- **S2 绝不覆盖**：默认跳过；可选「自动改名」（`名字 (n).ext`，n 从 1 递增找空位）
- **S3 临时文件协议**：写 `.<最终名>.xfertmp` → 复制完成 → 校验 → 仅当目标不存在时 `rename()` 转正；期间出现同名按 S2 策略处理
- **S4 完成校验**：字节数比对必做；深度校验开关 = CryptoKit SHA-256 逐字节比对
- **S5 取消安全**：立即停止后续任务；只清理「本次运行登记 + 命名模式匹配」的自有临时文件
- **S6 可写门**：目标不可写时阻止开始并给出指引

## 功能

| 编号 | 功能 |
|---|---|
| F1 | 拖拽区：拖入文件/文件夹，递归展开、去重、保留相对目录结构 |
| F2 | 目标文件夹：系统选择器 + 记住上次位置 + 在 Finder 中打开 |
| F3 | 队列列表：名称 / 大小 / 状态（待复制 · 复制中 · 已跳过 · 已完成 · 失败） |
| F4 | 进度：总进度条 + 当前文件 + 速度 + 剩余时间估算 |
| F5 | 冲突策略：跳过（默认） / 自动改名 |
| F6 | 深度校验开关（默认关） |
| F7 | 挂载状态条：显示目标卷名与只读/可读写状态；只读时提供重挂载入口 |
| F8 | 完成报告：成功 / 跳过 / 失败计数，失败清单可复制 |
| F9 | 保留修改时间（mtime） |
| F10 | 先拷后开：把清单项复制到本机临时目录并打开 |
| F11 | 环境自检：导出目标可写性、文件夹权限、挂载信息 |
| F12 | 文件日志：`~/Library/Logs/硬盘复制助手.log` |

## 非目标

不做删除、不做覆盖、不做双向同步/镜像、不做云同步、不管理分区、不格式化磁盘。

## 交付形态

- Swift 5 + AppKit 单窗口，`swiftc` 编译为 `.app`（ad-hoc 签名）
- 重挂载 helper：`app/mount-rw.command`，自动识别 NTFS 分区，经 Terminal 触发系统管理员授权
- 不自行提权、不内置任何凭据

## 验收

```bash
bash check.sh
```

覆盖：编译产出、S1 删除 API 审计、启动冒烟、复制引擎回归 12 项。
